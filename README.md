# Abhishek Kumbhar - Spring Boot Portfolio

A single-page responsive portfolio built with Spring Boot, Thymeleaf, HTML, CSS and JavaScript.

## Run in Eclipse

1. Import the folder as **Maven > Existing Maven Projects**.
2. Make sure the project uses **JDK 17 or newer**.
3. Run `PortfolioApplication.java` as a Spring Boot application.
4. Open `http://localhost:8080/`.

## Edit content

Most profile content is in:

`src/main/java/com/abhishek/portfolio/config/ProfileConfig.java`

Page HTML:

`src/main/resources/templates/index.html`

Styles:

`src/main/resources/static/css/style.css`

JavaScript:

`src/main/resources/static/js/app.js`

Photo:

`src/main/resources/static/img/photo.png`

Resume:

`src/main/resources/static/resume.pdf`
